# Art – theo tính năng
Mỗi thư mục gom đủ mesh + material + texture của một tính năng: Ammo, Balls, Board, Conveyor, Environment, VFX, UI/{Booster,Capacity,Common,Hud,Popup,Win}.
`Shared/` = thứ dùng chung nhiều tính năng (Colors, Materials, Physics, Textures).
Thay asset: GHI ĐÈ file (giữ .meta) hoặc kéo asset mới vào ô ở GameConfig/UiSkin. Di chuyển file chỉ trong Unity để giữ GUID.
Xem ../../ARCHITECTURE.md (bảng "muốn đổi X thì vào đâu").
