# Bounce Blast (bản làm lại)

Dựng lại game puzzle bắn bi **Bounce Blast** trên Unity 2022.3.62f3 (Built-in RP, Gamma), dùng asset khôi phục từ game gốc.

- **Bắt đầu đọc:** [`ARCHITECTURE.md`](ARCHITECTURE.md) – bản đồ dự án, muốn đổi gì thì vào đâu.
- **Quy ước code:** [`CODING_CONVENTION.md`](CODING_CONVENTION.md)
- **Toàn bộ tài liệu:** [`Docs/README.md`](Docs/README.md) – mục lục kiến trúc, thiết kế, tra cứu, lịch sử.
- **Nhật ký thay đổi:** [`Docs/devlog.md`](Docs/devlog.md)

Mở scene `Assets/_Project/Scenes/MenuGame.unity` (hoặc `Gameplay.unity` để vào thẳng màn chơi) rồi bấm Play.
